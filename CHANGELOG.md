# Changelog

The `[PCN "1.0"]` value in files names the format family and does not change while the document is a draft. The document is versioned by revision.

| Document | Date | Notes |
|---|---|---|
| Draft, 6th revision | 2026-09-29 | Current. `End` attributes `hh=` / `curl=` (ice from that end on) and `orderR=` / `orderY=` (delivery rotation from that end on, for substitutions and the mixed doubles order); `p=` can refer to alternates, numbered after `Players`; `curl` in the `Ice` tag is now defined as how far a tee draw aimed down the centre line ends up off the aim line (previously: sideways movement from the near hog line), and `turns=` (standard turns per delivery, default 5) is added |
| Draft, 5th revision | 2026-09-04 | Published in this repository (previously part of the CurlFlux repository) |
